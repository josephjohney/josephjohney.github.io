# josephjohney.github.io

Portfolio site deployed to GitHub Pages (static Create React App build).

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000). The dev server uses SPA mode so routes like `/resume` and `/projects` work the same as on GitHub Pages.

To use a different port:

```bash
npx serve -s . -l 8080
```
